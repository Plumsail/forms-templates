# Plumsail Forms templates

Ready-made form templates for [Plumsail Forms](https://plumsail.com/forms/). Each `.json` file is a form you can import and tweak instead of building everything from scratch.

## What's in here

- **100+ form templates** covering common scenarios: contact forms, leave requests, order forms, surveys, HR / employee forms, medical questionnaires, rental agreements, and more
- **`images/`** – background images and banners used by some of the templates
- **`data/`** – a few sample data files referenced by certain templates
- **`templates.xlsx`** – spreadsheet listing of the available templates

## How to use a template

1. Open the form you want (or download the `.json` file from this repo).
2. In Plumsail Forms, import / open the template JSON.
3. Adjust fields, layout, and branding for your site or process.
4. Publish and attach it to SharePoint, Microsoft Lists, or a public web form as needed.

Product docs: [Plumsail Forms documentation](https://plumsail.com/docs/forms-web/)

## Contributing

Got a useful form you'd like to share? Open a pull request with the template JSON (and any images it depends on under `images/`). Keep the filename clear so people can find it easily.
